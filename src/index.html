📖 How to Connect Your Google Sheet (Step-by-Step)
  1. Open your Google Sheet. Ensure it has 3 tabs named exactly: Equipment, Students, and Checkouts.
  2. Click on Extensions > Apps Script in the top Google Sheet menu bar.
  3. Delete any default code in the script editor, and paste the copyable Google Apps Script code below.
  4. Click Deploy > New deployment (top right). Select type Web app.
  5. Set Execute as: Me and Who has access: Anyone. Click Deploy.
  6. Copy the resulting Web App URL and paste it into the input box above!
